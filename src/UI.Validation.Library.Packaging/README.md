# Vodafone Robotics UI Validation Activities

UiPath Windows activities for **Validated Get Text**, **Validated Type Into**, and **Validated Click**.

Each activity exposes independent complete-selector inputs for PreCondition, Do Work, and PostCondition stages, privacy-safe structured logging, classified failures, bounded retry behavior, and a common `UIValidationResult` output.

Install this package in a modern UiPath Windows project and find the activities under **UI Validation**.
